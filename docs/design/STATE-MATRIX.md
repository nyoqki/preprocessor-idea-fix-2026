# Матрица экран × состояние × тема

Все состояния ниже используют общие семантические токены и доступны в светлой **и** тёмной теме. Это описание реализации, а результаты выполненных проверок приведены отдельно в [QA.md](QA.md) и [машинном отчёте](evidence/implementation/browser-report.json).

`npm run dev:mock`, затем `http://localhost:5173/?theme=light&scenario=…&role=student#/…`. Для тёмной темы заменить `light` на `dark`. Учитель — только dev-параметр `role=teacher`. [Каталог](http://localhost:5173/?catalog=1) помогает собрать ссылку, выбрать тему и сбросить демо-ответы. В production параметры роли/сценария игнорируются.
