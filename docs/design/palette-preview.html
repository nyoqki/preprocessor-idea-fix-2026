A показывает исходные цвета MAX UI. B — выбранное контрастное направление с уточнением пользователя: белые подписи основных кнопок в обеих темах. Это образцы цветов для создания экранов.

Кнопка:

B · Белые подписи в обеих темах

Основная кнопка сохраняет синий фон и белый текст в обеих темах: 5,57:1 в обычном состоянии, 6,40:1 при наведении и 7,47:1 при нажатии. Голубой в тёмной теме используется для ссылок, фокуса и границы кнопки. Статусы имеют отдельные контрастные пары.

Пользователь выбрал контрастное направление и белые подписи. Промпт ведёт сразу к созданию экранов. Переключатели этой страницы меняют только просмотр.
