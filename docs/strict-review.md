# Проверка проекта

Дата: 07.11.2026. Проверены бот, API, мини-приложение, работа с AI,
математическая проверка, база данных, сборка и документы из архива.
Результаты запусков собраны в [verification.md](verification.md).

## Сколько баллов сейчас

Без проверки внутри MAX моя оценка - **15/20**. Это оценка кода и того,
что удалось проверить локально. Окончательные баллы ставит жюри.
Правила: [п. 10.4, редакция 06.10.2026](https://cloud.mail.ru/public/HPwf/UHMcjpUay).

| Критерий                 | Балл | Чего не хватает                                                                                                                     |
| ------------------------ | ---- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Соответствие требованиям | 4/5  | Проверить реальные рукописные фото и весь путь ученика в MAX.                                                                       |
| UX и дизайн              | 4/5  | Дать новичку пройти путь без подсказок команды и проверить персонализацию у двух учеников.                                          |
| Стабильность и отклик    | 3/5  | Проверить задержки с настоящим AI и восстановление после сбоев. Причина разрывов HTTP-соединений под нагрузкой пока не установлена. |
| Мобильность архитектуры  | 4/5  | Показать смену AI-провайдера и запуск на другом сервере.                                                                            |

Для официальной оценки первый пункт нельзя отделить от MAX:
правила требуют работающего сервиса внутри мессенджера.

## Что исправлено

| Проблема                                                           | Что теперь происходит                                                                         |
| ------------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| Два подтверждения одной работы дважды учитывали ошибку             | Работа и карта сохраняются одной транзакцией. Поздний повтор отменяется.                      |
| Параллельные ответы оставляли тест активным                        | Ответы проходят под блокировкой. После последнего ответа тест завершается.                    |
| Поздний ответ AI возвращал данные после `/delete`                  | Перед сохранением заново проверяется согласие. История и работа не создаются повторно.        |
| Уточнения обходили лимит и могли раскрывать ответ                  | Они используют общую квоту и проверку утечки ответа. Любой обход модели это не исключает.     |
| Конспект передавался как системная инструкция                      | Теперь он передаётся как справочный текст отдельно от правил бота.                            |
| Роль учителя оставалась после снятия прав в чате                   | Права MAX проверяются при подключении, открытии сводки и её отправке.                         |
| Бот обрабатывал материалы незнакомых участников                    | Теперь нужны подключение к этому классу и согласие отправителя.                               |
| Ученик мог подтвердить свою родительскую ссылку                    | Такое подтверждение отклоняется. Возраст и родство бот не проверяет.                          |
| Сводка раскрывала сведения об одном ученике                        | Единичные группы скрываются. Полную анонимность это не гарантирует.                           |
| Огромный ID, дата или повреждённая подпись вызывали ошибку сервера | Входные значения проверяются до работы с БД. ID уже хранились в BIGINT, миграция не нужна.    |
| Production webhook работал без секрета                             | Теперь нужен непустой секрет; размер тела ограничен 1 МиБ.                                    |
| Длинный ответ не помещался в сообщение MAX                         | Текст делится на части до 4000 символов.                                                      |
| Сетевой обрыв при скачивании фото не обрабатывался                 | Размер и время скачивания ограничены, ошибка возвращается через MAX-клиент.                   |
| После сбоя работа оставалась в обработке                           | Есть сроки выполнения; незавершённая работа получает `failed`. Готовый результат сохраняется. |
| Таймаут браузера не охватывал чтение JSON                          | Теперь ограничено и получение тела ответа. Можно повторить запрос.                            |
| Неуверенно распознанная тема становилась линейным уравнением       | При низкой уверенности тема не назначается.                                                   |
| Сбой блокировал отправку уведомления навсегда                      | Неотправленную запись можно занять заново через 15 минут. Сетевой отказ освобождает её сразу. |
| Кнопка "Позже" обещала незапланированное напоминание               | Вместо обещания бот объясняет, как вернуться через `/quiz`.                                   |

## Что облегчено для слабого сервера

- Worker по умолчанию выполняет 4 задачи вместо 20.
- SymPy использует один дочерний процесс вместо двух.
- API и worker открывают до 5 соединений с БД каждый вместо 20.
- При чтении экранов профиль больше не перезаписывается каждый раз.
  Последнее посещение обновляется раз в пять минут; новое имя и доступность диалога
  обновляются сразу. Роль и согласие читаются из БД при каждом запросе.

Это ограничивает одновременную работу и убирает лишние записи в БД.
Ускорение в процентах не измерялось. Если задач много, очередь будет длиннее.
Параметры для ещё меньшего параллелизма есть в [README](../README.md#для-слабого-сервера).

## Что осталось

1. Полный путь в настоящем MAX пока не проверен: подключение, фото, подсказка,
   карта, тест и сохранение результата.
2. Распознавание проверялось на трёх печатных примерах. Для оценки точности
   нужны реальные рукописные работы с заранее известным правильным разбором.
3. Под высокой нагрузкой были разрывы HTTP-соединений. Счётчики не испортились,
   но точная причина сбоя не найдена. Изменение keep-alive клиента не считается
   исправлением сервера.
4. Между отправкой уведомления и записью результата процесс может упасть.
   Поэтому обещать доставку ровно один раз нельзя.
5. Бот не проверяет возраст и родство. Правила школьного пилота и обработки
   фотографий нужно согласовать отдельно.
6. Выгрузки нового опроса на 439 ответов нет. Проценты пока не пересчитаны.
7. Оригиналы презентации и анкеты не менялись. [Список правок](presentation-review.md)
   нужно применить к самим файлам.
